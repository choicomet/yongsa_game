# 용사와 배경의 시각적 조화

진한 검은 외곽선, 밝은 소매, 고해상도 그림을 Nearest로 크게 축소할 때 생기는 잔선 때문에 용사가 자연스러운 방 배경 위에 따로 붙인 것처럼 보였다. 용사 6포즈 시트를 수정하고 축소 처리도 조정했다.

[전후 비교 페이지](index.html)에서 캠프의 모든 자세와 세 던전의 정면을 확인할 수 있다. 실제 게임의 `WorldRenderer`로 같은 위치·조명·115% 배율에서 촬영한 화면이다. UI만 생략했으며, 비교 화면의 확대는 게임 카메라 변경이 아니다.

## 변경

- `assets/world/hero-harmony-v1.png`: 1536×1024, 투명 배경 3×2 시트. 갈색 머리·붉은 목도리·남색 옷·갈색 장비와 6포즈를 유지했다. 검은 실선의 무게를 줄이고 머리·옷·가죽의 그림자색으로 연결했다. 소매는 따뜻한 아이보리로 눌렀다.
- `assets/data/hd-art.json`: 인게임 용사 6개 영역만 새 시트에 연결한다. 논리 크기는 기존과 동일한 18×24, 게임에서는 SCALE=2로 표시된다. 캐릭터 이동·피격 판정·공격 범위는 바꾸지 않았다. 컷 경계는 360×500으로 맞추고, 발의 높이 차이를 0.5 월드 픽셀 미만으로 유지했다.
- `HdArt.Entry.pixelMip`: 용사 시트만 밉맵 사이를 혼합하고 각 단계의 텍셀은 Nearest로 읽는다 (`MipMapNearestLinear` / `Nearest`). 순수 Nearest의 거친 잔선을 줄이면서, 전체를 선형 필터링한 비교안보다 도트의 선명함을 남긴다. 같은 시트의 모든 영역은 같은 정책이어야 한다.

메뉴의 상세 일러스트, 무기·몬스터·다른 소품, 카메라 설정은 기존 자료를 사용한다. 이전 용사 시트 `assets/world/hero.png`도 보존했다.

## 재현과 검증

Java 17:

```text
gradlew :core:test :lwjgl3:dist
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.HeroHarmonyLauncher <출력폴더>
```

Windows 한글 경로 환경에서는 로컬 ASCII 클래스패스 init script를 더해 검증했다. 게임 실행의 의존성이 아니다.

- 전체 테스트 66개: 실제 이미지 영역, 투명 여백, 월드 크기, 포즈별 발 높이, 시트 내 축소 설정의 일관성을 포함한다.
- `HeroHarmonyLauncher`: 실제 렌더러로 캠프·광산·성채·탑 × 7상태(6포즈와 왼쪽 반전), 총 28개 화면을 출력한다. 사용자 세이브와 분리된 경로를 사용한다.
- 선택 비교 옵션 `original`은 같은 최신 맵에서 이전 용사를 재현한다. `nearest`, `pixel-mip`은 수정 시트의 축소 방식을 비교한다. 모두 캡처 실행에만 적용되며 옵션 없는 실행이 게임 기본 결과다.

새 시트는 built-in imagegen의 편집 모드로 만들었다. 참고는 기존 인게임 용사와 중앙캠프 배경이며, [최종 프롬프트](imagegen-prompt.txt)를 보관했다. PNG를 별도 도구로 리터칭하거나 재양자화하지 않았다.

## 적용 순서

중앙캠프 PR #4는 클로드 브랜치에 병합됐다. 이 후속 변경은 클로드의 캠프 길·출입구 수정 `46f0898` 위에서 검증한다. 전경 가림 레이어, 맵 소품의 애니메이션, 전체 몬스터의 스타일 조정은 이번 변경 범위에 포함되지 않는다.
