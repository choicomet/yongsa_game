# 검수 기록 — 2026-10-10

## 제작 경로

1. 이전 용사·성검 그림을 참조해 내장 image_gen으로 질감과 장식을 줄인 디자인 시안 2장을 생성했다. 프롬프트는 `PROMPTS.json`에 있다. 알파를 포함한 원본 그대로 `concepts/`에 복사했다.
2. 기존 게임의 `palette` / `sprite` 텍스트 형식에 맞추어 픽셀 원본 2종을 별도로 작성했다. 생성 PNG를 축소하거나 양자화한 결과가 아니다.
3. Node.js 작성 소스 → 텍스트/JSON → JDK 17 PNG 출력으로 재현했다. 런타임 Java 소스와 게임 데이터는 수정하지 않았다.

## 자동 확인

- 용사: 32×48, 가시색 22개, 반투명 픽셀 0개, 가시 영역 (4,3)부터 27×42.
- 성검: 32×32, 가시색 10개, 반투명 픽셀 0개, 가시 영역 (2,3)부터 28×27.
- 모든 행의 가로·세로 길이, 팔레트 기호, 불투명/투명 알파 값, 프레임 여백 확인.
- 1·2·4·8배 PNG를 저장한 뒤 다시 읽어 각 출력 픽셀이 원본의 정확한 정수배 블록과 일치하는지 확인.
- 위 항목은 `native/VALIDATION.json`으로 재생성된다. 팔레트 예산 24색은 이번 샘플의 검수 기준이며 프로젝트 전체 제한이 아니다.
- 비교 화면과 README의 로컬 파일 링크 27개, 인라인 스크립트 구문 확인.
- 브라우저에서 2→4→2배 전환, 격자와 기준점 켜기/끄기, 청회색↔흙빛 배경 변경을 확인하고 최종 화면을 캡처했다.

## 검증 범위

정면 대기와 검의 정적인 형태 및 픽셀 데이터 검증이다. 전체 걷기/공격 애니메이션, 실제 손잡이 연결, 카메라·적 사거리, Java 게임 안에서의 플레이 가독성은 아직 검증하지 않았다. 생성 시안 PNG 자체는 고정 그리드나 제한 팔레트 충족을 주장하지 않는다.

Java 게임 코드가 바뀌지 않았으므로 게임 전체 빌드/전투 테스트를 이번 아트 작업 때문에 반복하지 않았다. 실행한 Java 검증은 독립된 텍스트 자산 내보내기 도구다.
