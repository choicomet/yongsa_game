# 런타임 연결 전 확인 사항

> 기록용 문서입니다. 이후 사용자는 2번 생성 시안을 인게임용으로 선택했습니다. [최신 실제 적용본과 대장간 변경](../style2-runtime/README.md)을 먼저 확인하세요.

2026-10-10 원격 구현 브랜치의 `3cad8eb`까지 확인했다. Claude는 `1492056`에서 카메라 비교 기능을 구현하고 `3cad8eb`에서 v3 생성 시안을 게임 이미지로 교체했다. 이번 v4 원본은 아직 런타임에 연결하지 않았다. 이후 구현이 있다면 최신 코드를 먼저 비교한다.

## 원본과 좌표

| 자산 | 프레임 | 기준점 (왼쪽 위 원점) | 상태 |
|---|---|---|---|
| hero_down | 32×48 | 발 (15,45), 오른손 참고 (23,31) | 정면 대기 1프레임 |
| sword_holy | 32×32 | 손잡이 (6,26), 기본 날 방향 45° | 기본형 1종 |

용사는 프레임 안에서 발 기준점을 고정한다. 이후 걷기에서 발끝 픽셀이 이동해도 프레임 피벗은 같아야 한다. 좌우 반전 시 손 위치도 반전한다. 아직 옆·뒤·걷기 프레임은 없다.

검 손잡이의 왼쪽 위 기준 (6,26)은 32칸 높이에서 아래쪽 기준 (6,6)에 대응한다. 현재 `WorldRenderer.drawSword()`의 원점 `(6,6)`, 기본 방향 보정 `angle - 45`와 맞추기 위한 기준이다. 실제 잡는 손 연결은 방향별 검토가 필요하다.

## 그대로 파일만 바꾸면 안 되는 이유

- `Art.java`는 이미 텍스트 픽셀 자산과 Nearest 아틀라스를 지원한다. 이번 텍스트는 기존 전체 팔레트와 다른 기호 정의를 사용한다. 전역 팔레트나 `assets/data/sprites.txt` 전체를 덮어쓰면 다른 몬스터·소품의 색이 바뀌거나 자산이 누락된다. 별도 팔레트로 내보낸 PNG를 로드하거나 전용 로더로 연결한다.
- `HdArt.java`는 현재 mipmap + Linear 필터를 쓰며 HD 항목이 우선이다. 픽셀 PNG를 기존 HD 경로에 넣기만 하면 부드러워질 수 있다. 픽셀 자산용 Nearest 설정과 mipmap 비활성화가 필요하다.
- `WorldRenderer.drawHero()`는 `art.width/height * Art.SCALE`을 사용한다. 원본이 16×20에서 32×48로 바뀌었다고 월드 크기까지 자동 확대하면 안 된다. 그림 해상도와 표시 크기를 분리해 지정한다.
- 현재 용사 그리기는 프레임 아래쪽을 기준으로 한다. 여백이 있는 새 프레임은 발 피벗을 반영해야 바닥 그림자와 어긋나지 않는다. 검은 이미 별도 회전 중심을 사용한다.
- `TextureFilter.Nearest`만으로 모든 화면 픽셀이 일정한 폭을 갖는 것은 아니다. 창 크기, FitViewport, 카메라, 회전과 스쿼시가 최종 배율을 바꾼다. 안정된 도트 크기가 필요하면 고정 해상도 월드 버퍼를 정수배 표시하는 방식을 검토한다. HUD는 별도 해상도를 유지할 수 있다.
- 회전·구르기·공격 변형에서 생기는 도트 흔들림도 확인한다. 지금 대기 이미지의 정수배 검증을 런타임의 모든 동작 검증으로 확대 해석하지 않는다.

## 카메라는 별도 비교

기준 배율 100%의 `ZOOM=2/3`, 세로 720, 타일 32에서는 높이 15칸이 보인다. 최신 기본값인 일반 115%에서는 약 13.04칸, 보스방 100%에서는 15칸이다. 120%면 12.5칸이다. 일반 보스방은 15칸, 최종방은 16칸이다. 맵 경계 클램프, 위쪽 16 월드 단위 오프셋, 추적 지연과 HUD 때문에 방 높이와 뷰 높이가 같아도 전체 공격 정보가 항상 보장되지는 않는다.

현재 마족병 공격 조건은 거리 7칸이며 카메라 가시성 조건이 없다. Claude도 사거리 변경은 비교 뒤로 보류했다. 구현된 **휠/+/- 비교 기능**으로 화면 밖 공격 가능성과 예고 노출을 확인한다. 일반 115%에서 다시 15%를 더 확대하라는 제안이 아니다. 사거리 5.5칸은 초기 조정 후보였으며 확정 요구사항이 아니다. 카메라 비교 후 예고 노출과 전투 밸런스를 보고 결정한다.

소스 픽셀 확대와 카메라 상대 확대는 다른 수치다. 갤러리의 2배 표시는 이미지 원본의 정확한 정수배이며, 게임 카메라 +15%를 재현한 것이 아니다.
