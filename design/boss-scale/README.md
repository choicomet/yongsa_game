# 보스 크기 후속 조정

용사·일반 몬스터를 25% 확대한 뒤 골렘의 덩치가 상대적으로 약해 보였다. 골렘은 이전 보스 크기에서 가로·세로 25%, 혈월의 기사·탑의 수문장·마왕은 15% 확대한다. 용사·잡몹의 추가 확대는 없다.

[실제 보스방 전후 비교](index.html)는 `9b613c5`의 보스 크기와 이번 변경을 같은 원본 그림·조명·위치·보스방 기본 카메라 100%에서 비교한다. 캐릭터 중심 보기는 사진을 동일하게 잘라 보여주며 전체 화면도 볼 수 있다. 캡처는 비교용 고정 배치로 UI를 생략한 실제 WorldRenderer 출력이다. 전투 녹화나 모든 화면 가장자리 상황의 검증을 의미하지 않는다.

## 크기와 연출

| 보스 | 가로×세로 그림 영역, 월드 단위 | 추가 배율 |
| --- | --- | --- |
| 골렘 | 85×91.8 → 106.25×114.75 | 1.25 |
| 혈월의 기사 | 74.8×88.4 → 86.02×101.66 | 1.15 |
| 탑의 수문장 | 74.8×88.4 → 86.02×101.66 | 1.15 |
| 마왕 1페이즈 | 96×116 → 110.4×133.4 | 1.15 |
| 마왕 2페이즈 | 110.4×133.4 → 126.96×153.41 | 1.15 |

용사는 45×60이다. 골렘 그림 영역 높이는 용사의 약 1.91배다. 위 수치는 투명 여백을 포함한다. 원본 PNG를 늘리거나 다시 그리지 않고 렌더링 크기만 변경했다.

- `WorldRenderer.bossScale(sprite)`를 생존·변신·사망 렌더링에 공통 적용한다. 그림자와 머리 위 표시도 새 몸 크기를 따른다.
- 몸을 둘러싼 보호막·마왕의 기운·소환 빛·시전 빛의 크기를 함께 조정하고, 보스 말풍선의 시작 위치를 그림 위로 올린다.
- 마왕이 2페이즈에서 죽을 때 사망 이벤트가 1페이즈 배율 2.0을 보내던 것을 2.3으로 수정했다. `GameSession` 변경은 이 연출 메타데이터 한 줄이다. 기존 부활 테스트에서 최종 사망까지 진행하고 사망 배율을 검증한다.
- 이동 경계, 피격 원, 공격 거리·대미지·속도, 내려찍기와 돌진 등의 바닥 예고 범위, 카메라 확대율과 세이브 형식은 유지한다. 보호막 빛과 공격 범위 표시는 역할이 다르므로 몸 확대 배율을 공격 판정에 적용하지 않는다.
- 큰 보스 머리가 상단 HUD에 가려지지 않도록 보스전에서 카메라 목표 높이를 제한적으로 올린다(화면 높이의 최대 23%). 비교 페이지의 고정 배치 캡처와 달리 실제 플레이 카메라 위치는 이 보정을 받는다.

## 검증

Java 17 `:core:test :lwjgl3:dist` 성공. 전체 66개 테스트 통과(실패·오류 0). 기존 마왕 부활 테스트에 2페이즈 사망 크기 검증을 추가했다.

```text
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.ActorScaleLauncher <출력폴더>
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.VisualSmokeLauncher <출력폴더>
```

`ActorScaleLauncher`는 기존 13장에 보스방 9장을 추가해 총 22장을 출력한다. 이 폴더에는 보스 4종, 골렘 내려찍기·보호막·사망, 마왕 변신·2페이즈의 전후 18장을 보관했다. `VisualSmokeLauncher`의 21개 시나리오 및 제작·장착·강화 입력 검증도 통과했다. 캡처 실행은 별도 세이브 경로의 숨김 창을 사용한다.

카메라 보정 후 2026-10-15에 실행 검사를 다시 완료했다. `hud/tower-boss.png`, `hud/final-boss.png`에서 보스 머리가 상단 HUD 아래에 표시되는 것을 확인했다. 모든 전투 위치나 화면 크기의 검증을 뜻하지는 않는다.

클로드 구 기준 `46f0898` 위에서 작업했으며 PR #5에 앞선 용사 외곽선·용사와 잡몹 확대 변경과 함께 포함한다. 이 문서가 이전 actor-scale 기록의 “보스 크기 유지”보다 최신 결정이다.

**팀 통합 브랜치 적용 주의:** 현재 `claude/team-integration-m9u9aa`는 256px 칸의 보스 동작 시트와 별도 렌더러를 쓴다. 이 PR은 이전 단일 그림 렌더러 작업을 마무리한 기록이며 팀 통합 브랜치에 그대로 병합하는 용도가 아니다. 새 코드에서의 보스 크기·카메라 조정은 Claude가 현재 렌더러에 맞춰 옮겨야 한다. 새 A~D PR은 그림·맵 데이터만 포함한다.
