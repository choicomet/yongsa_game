# 용사와 검 · 도트 디자인 1차

2026-10-10. 사용자가 캠프 도트 시안의 방향을 긍정적으로 평가하고, 캐릭터와 무기 디자인을 먼저 요청했다.

## 이번 제작 범위

- 용사: 앞/뒤/오른쪽의 대기와 걷기 포즈를 같은 디자인으로 표현한 6포즈 시트. 무기는 별도 레이어로 사용할 수 있도록 캐릭터 손에 합쳐 그리지 않는다.
- 검: 봉인된 성검, 깨어난 성검, 흑철검, 심연의 흑철검, 혈월검, 만월의 혈월검, 천공검, 뇌명의 천공검. 각각 별도 투명 PNG 디자인.
- 기존 모습의 정체성을 유지하면서 손으로 정리한 듯한 픽셀 덩어리, 제한된 명암, 단순하고 읽기 쉬운 실루엣으로 조정한다.
- 실제 게임 적용 전 디자인 단계다. 생성 시트의 그리드/포즈 중심/픽셀 밀도는 런타임 연결 전에 별도 정렬·검증해야 한다.

## 용사

갈색 머리, 붉은 목도리, 남색 상의, 크림색 소매, 갈색 장갑/부츠/벨트를 유지한다. 현실적인 옷 주름과 가죽 무늬를 줄이고 얼굴·손·발·목도리 방향이 작은 크기에서도 보이도록 한다. 극단적인 큰 머리나 사실적인 인체 비율로 바꾸지 않는다. 작은 모험가 캐릭터로 통일한다.

## 검의 구별

| 종류 | 기본형의 핵심 | 각성형의 변화 |
|---|---|---|
| 성검 | 상아빛 직선 날, 절제된 금색 가드, 봉인 띠 | 봉인이 풀린 맑은 날, 간결한 날개 가드, 따뜻한 중심빛 |
| 흑철검 | 넓고 무거운 암청색 날, 단순한 가드 | 더 뚜렷한 각진 날끝과 한 줄의 푸른 균열 |
| 혈월검 | 붉은 곡선 날, 작은 원형 중심석 | 초승달을 강조한 날과 한 개의 열린 원형 가드 |
| 천공검 | 길고 가는 청색 날, 짧은 대칭 가드 | 갈라진 번개 형태의 날끝과 보라/청색 포인트 |

색만 바꾼 같은 검이 되지 않게 한다. 기본형부터 화려한 보석·가시를 증식시키지 않으며, 각성 차이는 큰 형태 하나와 제한된 강조색에 둔다.

## 도트 규칙

원본 해상도 제한을 다시 두지 않는다. 생성 이미지에는 선명한 픽셀 형태를 요청하지만, 큰 PNG가 곧 정확히 정렬된 네이티브 도트 원본이라는 뜻은 아니다. 실제 게임용으로 확정할 때 일정한 제작 그리드·정수 배율·표시 크기를 결정한다. 품질 검토는 확대 그림과 작은 장착 크기 양쪽에서 한다.

투명 PNG에는 바닥 그림자·발광 배경·그려진 체크무늬를 넣지 않는다. 검은 모두 손잡이가 왼쪽 아래, 날끝이 오른쪽 위인 약 45도 방향을 기준으로 한다. 크롭 경계나 손잡이 기준점은 후속 실제 적용 시 계산한다.

## 중앙방 — 후속 작업으로 기록

사용자 의견: 타이틀 화면 스크린샷 같은 느낌으로 중앙방을 나중에 만들면 좋겠다. 현재는 사각형 방에 고정된 느낌이 강하다.

후속 방향: 모닥불을 중심으로 불규칙한 캠프 외곽을 만들고, 무너진 벽·암벽·작은 작업 구역으로 대장간과 침대를 배치한다. 던전 입구는 자연스러운 통로 끝에 두며 빈 공간 크기를 다르게 해 직사각형 테두리의 반복을 완화한다. 구체적 배치와 이동 동선은 캐릭터/무기 디자인 다음 단계에서 검토한다. 현재 방 데이터나 충돌 구조는 이번 작업에서 바꾸지 않는다.

제작 도구: 내장 `image_gen`. 각 이미지에 사용한 입력 역할과 프롬프트는 `PROMPTS.json`에 보존한다. CLI 또는 외부 API로 대체하지 않는다.
