# 디자인 검수 기록

2026-10-10. 디자인 시안 검수이며 게임 실행 검증과 구분한다.

## 시각 확인

- 용사: 앞/뒤/오른쪽의 대기·걷기 6포즈, 무기 미합성, 붉은 목도리·남색 옷·갈색 장비의 일관성 확인.
- 검: 각 이미지에 한 자루씩 분리. 기존 네 계열의 주요 형태·색을 유지하면서 작은 장식과 실사 질감을 줄임.
- 기본형과 각성형은 비교 갤러리에서 나란히 확인할 수 있음.
- 모든 이미지의 내용은 내장 이미지 생성 결과를 직접 보고 확인. 복사 과정에서 재압축·확대·배경 제거 등 별도 이미지 편집은 하지 않음.

## 파일 확인

`IMAGE_INSPECTION.json`에 9개 PNG의 치수, 투명/반투명/불투명 픽셀 수, 알파 128 이상 영역의 경계와 SHA-256을 기록한다. 배경의 실제 알파와 그림이 캔버스 끝에 닿지 않는지 검사한다. HTML의 모든 이미지/문서 링크도 존재 여부를 확인한다.

검사 결과: 9개 이미지의 투명 배경·실제 내용·캔버스 여백 검사 통과. 캐릭터 시트는 1536×1024, 개별 검 8장은 각각 1254×1254다. HTML의 로컬 이미지·문서 참조도 존재한다. 브라우저별 최종 배치나 실제 게임 표시 크기를 실행 검증했다는 뜻은 아니다.

이미지 뷰어에 따라 투명 영역의 숨은 RGB가 어두운 색이나 번짐처럼 보일 수 있다. 실제 합성에서의 배경 유무는 PNG의 알파 채널로 판단한다. GitHub 업로드용 사본도 기록된 PNG 해시와 대조한다.

## 실제 적용 전에 남은 것

- 이 PNG들은 도트 스타일 디자인 시안이다. 한 가지 정수 픽셀 그리드에 모든 점이 정렬된 편집용 원본이라고 보장하지 않는다.
- 영웅 6포즈는 디자인/동작 기준이며 완전한 다중 프레임 보행·공격 애니메이션 세트가 아니다.
- 캐릭터 포즈별 크롭, 발 기준점, 팔과 검의 장착점, 좌우 반전 시 목도리 처리를 실제 렌더러에서 맞춰야 한다.
- 각 무기 원본의 보이는 길이를 게임 표시 크기에 맞추고 손잡이 위치·회전 기준점을 따로 정해야 한다. 현재 이미지 캔버스 크기가 공격 범위는 아니다.
- Nearest 표시, 카메라 이동, 작은 창과 정상 크기 창에서 픽셀 흔들림·윤곽 읽힘을 확인해야 한다.
- 실제 게임 소스/리소스/세이브는 변경하지 않았고, 이번 단계에서 Java 테스트나 실행 검증을 새로 수행하지 않았다.
