# 이전 인수인계 이후 디자인 방향 추가

저장소에서 작업할 때는 [공통 디자인 기준](../../docs/ART_DIRECTION.md)과 [협업 절차](../../docs/COLLABORATION.md)를 먼저 읽는다. 아래는 방향이 정해진 배경 기록이다.

2026-10-10. `claude-gameplay-handoff` 제작 이후 사용자 발언을 반영한 추가 기록이다.

1. 기존 디자인의 기본 틀을 기반으로 게임에 맞게 과한 부분을 덜어내고 싶다고 했다.
2. 사용자가 테라리아처럼 도트이면서 퀄리티가 높은 느낌을 제안했다. 참고 게임은 던그리드·코어 키퍼·테라리아다. 횡스크롤 전환이나 특정 게임의 시스템 복제 요청은 아니다.
3. 현재 캠프의 도트 방향 시안을 긍정적으로 평가했다.
4. 캐릭터와 무기 디자인을 먼저 요청했다. 이번 자료는 용사 6포즈와 검 기본/각성 8종의 디자인 시안이며, 게임에 연결한 런타임 자산으로 확정한 단계는 아니다.
5. 중앙방은 나중에 타이틀 화면 스크린샷 같은 느낌으로 만들면 좋겠다고 했다. 현재는 사각형 방에 고정된 느낌이 강하다는 의견이다. 후속 중앙 캠프 작업에서는 자연스러운 외곽, 구역별 대장간/침대/통로, 실제 이동 공간과 충돌도 함께 검토한다. 지금 즉시 모든 방을 재설계하라는 뜻으로 확대하지 않는다.
6. 제작 중 사용자가 디자인은 좋지만 실제 게임에서는 체감이 약하다고 했고, 카메라 확대나 캐릭터 크기 증가가 좋은지 물었다. 작성자는 우선 월드 카메라 15~20% 확대 비교, 이후 필요할 때 액터 표시 크기 5~10% 조정을 제안했다. 아직 사용자 확정 수치나 구현 완료 상태가 아니다. 자세한 내용은 `DISPLAY_SCALE.md`를 읽는다.

16×20 제한 해제, Java 유지, 검 별도 자산, 최신 사용자 의견 우선 원칙은 그대로다. 이번 디자인 자료가 기존 게임 규칙·세이브·게임성 개선 범위를 자동 변경하지 않는다.
