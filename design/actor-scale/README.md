# 넓어진 맵에 맞춘 용사·잡몹 크기

자연스러운 배경 방으로 전환한 뒤 맵에 비해 배우가 작게 보였다. 현재 카메라와 방 배치를 유지하면서 용사와 일반 몬스터를 가로·세로 각각 25% 확대했다. [전후 비교](index.html)는 실제 Java `WorldRenderer`를 같은 1280×720, 카메라 115%, 위치·조명·자세에서 촬영한 것이다. HTML에서는 두 캡처에 같은 배율을 적용한다.

## 적용 내용

| 대상 | 변경 전 → 변경 후 (월드 단위) |
| --- | --- |
| 용사 그림 영역 | 36×48 → 45×60 |
| 박쥐 그림 영역 | 54×42 → 67.5×52.5 |
| 해골병 그림 영역 | 36×46 → 45×57.5 |
| 마족병 그림 영역 | 42×44 → 52.5×55 |
| 손에 든 검 그림 영역 | 32×32 → 40×40 |
| 보스 / 마왕 | 기존 크기와 변신 배율 유지 |

투명 여백을 포함한 렌더링 영역의 크기다. 원본 PNG의 해상도는 바꾸지 않았다.

- `WorldRenderer.HERO_SCALE`, `MOB_SCALE`을 1.25로 지정했다. 걷기·좌우 반전·공격·구르기, 검의 손잡이와 걷기 상하 움직임, 발 그림자, 구르기 잔상, 잡몹 사망 그림에 같은 배율을 적용한다.
- 몬스터의 세로 변형과 떠 있는 높이를 공통 계산으로 분리했다. 체력 막대·공격 예고의 느낌표·기절 별은 같은 계산으로 얻은 그림 윗부분 위에 놓여, 머리와 겹치지 않는다.
- `hd-art.json`에서 몬스터 시트와 검 8종을 용사와 같은 `pixelMip` 축소 방식으로 맞췄다. `MipMapNearestLinear`는 밉 단계 사이만 혼합하고 각 단계의 텍셀은 Nearest로 읽는다. 같은 시트인 보스도 이 축소 처리만 공유하며 크기는 그대로다. 메뉴용 `hd/` 일러스트는 바뀌지 않는다.
- 이동 발판, 하체 중심 피격 원, 공격 사거리·속도·대미지·투사체·카메라 값은 유지한다. 칼 궤적과 바닥 공격 예고도 기존 실제 공격 범위를 나타낸다. 커진 그림 전체를 충돌 박스로 바꾸면 좁은 길이나 회피 난도가 달라지므로 표현 배율과 전투 판정을 분리했다.

이번 변경은 기존 몬스터 그림의 크기와 축소 처리 조정이다. 몬스터 원화의 외곽선·팔레트를 새로 그린 작업은 포함하지 않는다.

## 검증과 재현

Java 17에서 `:core:test :lwjgl3:dist` 실행. 전체 66개 테스트 통과, 실패·오류 0. Windows 한글 경로 환경에서는 로컬 ASCII 클래스패스 init script를 추가해 검증했으며 게임 실행 의존성이 아니다.

```text
gradlew :core:test :lwjgl3:dist
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.ActorScaleLauncher <출력폴더>
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.VisualSmokeLauncher <출력폴더>
```

- `ActorScaleLauncher`: 별도 세이브 경로와 숨김 창으로 13장 촬영. 캠프, 잡몹 3종과 골렘 비교, 광산·성채·탑, 공격 예고, 기절, 사망, 걷기, 왼쪽·위 방향, 공격, 구르기를 다룬다. 적은 비교를 위해 배치하며 실제 캠프 스폰은 바꾸지 않는다. 이 중 8개 장면의 전후 16장을 비교 페이지에 보관했다.
- `before/`: 용사 외곽선 수정이 적용된 `30b2696` 렌더러에 캡처 실행기만 더한 상태. `after/`: 이번 확대·축소 처리·표시 위치 조정 결과. 양쪽 모두 같은 용사 시트이며 배경·카메라는 동일하다.
- `VisualSmokeLauncher`: 타이틀, 캠프, 인벤토리, 전투 방, 보스, 작은 창, 무기와 대장간의 21개 시나리오 완료. 제작·장착·스크롤과 강화 성공/유지/하락/파괴/각성 결과가 한 번만 처리되는지 및 강화 중 입력 잠금 검증을 통과했다.

클로드 기준 브랜치 `46f0898` 위에서 적용했다. 게임 로직 파일·맵 데이터·세이브 형식은 수정하지 않았다. 캐릭터 외곽선 변경과 함께 PR #5에서 검토할 수 있다.
