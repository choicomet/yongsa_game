# 캠프와 던전 가림 층 검토 · A

## 검증 범위

- 이동·출입구·전투 문 잠금과 무너진 갱도 양쪽 입구 사이의 실제 용사 왕복을 포함한 JUnit 221개 통과.
- 116개 PNG 모두 원화와 같은 캔버스 크기이며 불투명 픽셀의 RGBA가 원화와 일치한다. 같은 장면의 가림 PNG 사이에 겹치는 불투명 픽셀은 없다.
- `SceneLayerSmokeLauncher OUTPUT`으로 용사와 해골병을 물체의 남·북·서·동에 배치해 실제 렌더러를 촬영한다. 일부 위치는 정렬 확인을 위해 강제로 배치하며 로그에 이동 가능 여부를 함께 기록한다.
- 현재 배치에서 원래 물체의 표본 위치가 모두 연결부·경계 아래에 있는 30개는 별도 표기한다. 이 경우 화면에서는 최종 연결부가 보여야 한다. 모든 윤곽의 1~2픽셀 미관은 팀 시각 검토 대상이다.

## 지형 판단

A 범위에서 추가 경사로 그림이 필요한 곳은 확인되지 않았다. 동굴 뒤쪽 침목이 놓인 흙길은 이동 가능하고, 갱도 앞 절벽과 떠 있는 선로의 가대는 막힌다. B·C의 탑 광석 수레 옆 틈과 광산 창고 단은 다음 검토 대상으로 남겨 두었다.
