# 효과음 · 배경음악 믹스

배경음악(보스방 곡 5개, PR #35)이 들어오면서 효과음을 곡에 맞춰 다시 정리했다.
규칙은 `core/src/main/java/com/yongsa/audio/SfxMix.java` 한 곳에 있다.

## 무엇이 바뀌었나

| 문제 (전) | 지금 |
|---|---|
| 효과음 크기가 제각각: 휘두르기 -23dB, 쿵(slam) -7dB, 16dB 차이. 곡을 틀면 휘두르기가 묻힘 | 소리마다 목표 크기를 정하고, 만든 파형을 재서 맞춤. 휘두르기 -15, 타격 -12, 맞음 -11, 쿵 -11 |
| 곡이 크게 마스터링됨 (약 -12 LUFS). 효과음과 같은 70%면 곡이 효과음을 덮음 | 곡은 안에서 0.6배로 낮춰 틂 (`Bgm.MIX`). 설정 70%에서 약 -19 LUFS |
| 한 번 휘둘러 셋을 맞히면 타격음 세 겹 | 같은 소리는 최소 간격 안에 다시 나지 않음 (타격 0.045초, 몹 공격 0.09초 등) |
| 몹이 몰리면 소리가 뭉개짐 | 0.25초 안에 6개 넘게 나면 덜 중요한 소리(휘두르기·몹 공격·발소리 등)를 줄임 |
| 포효·각성이 곡에 묻힘 | 큰 소리(포효·각성·봉인 해제·파괴·사망·귀환)가 나면 곡을 잠깐 내렸다(덕킹) 0.6초에 걸쳐 되돌림. 그동안 작은 효과음도 줄임 |
| 보스전 시작: 포효와 곡이 동시에 올라옴 | 곡을 먼저 틀고 포효가 곡을 눌러서, 포효가 끝날 즈음 곡이 올라옴 |
| 마왕 2페이즈: 1페이즈 곡이 뚝 끊기고 2페이즈 곡이 바로 | 변신(2.6초) 동안 1페이즈 곡을 0.8초에 걸쳐 거두고, 포효만 남긴 뒤 2.2초에 2페이즈 곡을 올림 |
| 상황과 상관없이 같은 소리 | 보스를 때리면 낮고 무거운 타격음(`hitBoss`), 체력 30% 밑에서 맞으면 더 낮고 큰 소리(`hurtLow`), 보스가 쓰러지면 무거운 처치음(`bossDown`), 0.6초 안에 연타하면 타격음이 한 단계씩 올라감(최대 4단계) |

## 소리 파일로 바꾸기

`assets/audio/sfx/<이름>.ogg` (또는 `.wav`, `.mp3`)를 넣으면 코드로 만든 소리 대신 그 파일을 쓴다.
코드 수정은 필요 없다. 이름은 아래 표의 이름과 같게 한다.

- 파일은 **가장 큰 부분이 -12dB 정도**(대충: 피크가 -3dB 근처, 꽉 채운 마스터링 아님)로 맞춰 오면 된다. 그 기준에서 목표 크기만큼 자동으로 줄인다.
- 앞에 빈 소리(무음)가 없게 잘라야 타격감이 맞는다.
- `hitBoss`, `hurtLow`, `bossDown`은 각각 `hit`, `hurt`, `kill` 파일을 높낮이만 바꿔 쓴다.

## 새로 있으면 좋은 소리 (요청 목록)

지금 효과음은 전부 코드로 만든 삐삐 소리라, 실제 녹음된 곡 옆에 두면 질감이 다르다. 효과가 큰 순서:

1. **배경음악이 보스방에만 있음**: 타이틀, 캠프, 던전 3곳(갱도·성채·탑), 엔딩 곡이 없어서 보스방을 나오면 조용해진다. 곡이 생기면 `game.bgm.play("camp", 1.5f)`처럼 한 줄씩 붙이면 된다.
2. 전투 기본: `swing`(검 휘두르기), `hit`(베는 타격), `hurt`(용사가 맞음), `kill`(몹 처치) — 가장 자주 나는 소리라 바꾸면 체감이 가장 큼
3. 보스 포효를 보스별로: 지금은 `roar` 하나를 넷이 같이 씀 (골렘 바위 울림, 기사 쇳소리 섞인 외침, 수문장, 마왕)
4. 몹 공격을 몹별로: `monsterAttack` 하나를 박쥐·해골·임프가 같이 씀
5. 문·발소리: `step`(문 지나갈 때), `gateClose_*` / `gateOpen_*`(던전별 전투문)
6. 대장간: `mine`(망치), `success` / `keep` / `down` / `destroy`(강화 결과), `craft`(제작)
7. 메뉴: `select`

## 2026-11-26 바뀐 점 (해성 요청)

- **기본 공격(휘두르기·타격음)과 구르기는 소리 없음.** 기본 공격으로 잡은 몹의 처치음(`kill`)은 남김.
- 녹음 효과음(`assets/audio/sfx/*.wav`, Kenney CC0)은 대신 **스킬과 보스 패턴**에 씀:
  - 스킬: `sk_cleave`(대지 가르기, 낮은 내려찍기) · `sk_crescent`(혈월참, 길게 끌리는 베기) · `sk_strike`/`sk_strikeHit`(천공 낙뢰, 모으기 → 깨지는 소리) · `sk_beam`(성광 검기, 맑은 종소리)
  - 보스·몹 장판이 터질 때 모양마다: `hz_boulder` `hz_rock` `hz_pound` `hz_quake` `hz_leap` `hz_spear` `hz_flame` `hz_spin` `hz_whip` `hz_bolt` `hz_cage` `hz_bone` `hz_tentacle` `hz_brand`. 규칙 없는 새 모양은 `slam`.
- 같은 녹음 파일을 높낮이만 바꿔 여러 곳에 쓴다 (예: 바위 = `destroy` 0.55배, 번개 = `destroy` 1.45배). 숫자는 `SfxMix`.

## 2026-11-26 스킬 소리 새로 만듦 (해성 요청: 스킬마다 특색 있게, 더 크게)

`tools/make_skill_sfx.py` 로 스킬마다 쓰는 소리와 맞는 소리를 따로 만들었다 (`assets/audio/sfx/sk_*.wav`). 다시 만들려면 `python tools/make_skill_sfx.py`.

| 스킬 | 쓸 때 | 맞을 때 |
|---|---|---|
| 흑철 · 대지 가르기 | 바위가 갈라지는 내려찍기 + 자갈 + 저음 | 바위 부서짐 |
| 혈월 · 혈월참 | (저주받은 칼날) 녹슨 쇠를 긁는 '끼이익' → 칼바람 → 여러 목소리가 낮게 웅얼거림 | 짧게 긁고 베는 소리 + 짧은 웅얼거림 |
| 천공 · 천공 낙뢰 | 올라가는 전기 윙 소리 + 지직거림 | '딱' + 유리 갈라짐 + 길게 구르는 천둥 |
| 깨어난 성검 · 성광 검기 | (검의 각성) 칼날 공명 '우웅'이 커지다 '콰앙' + 묵직한 여운 (종소리 없음) | 묵직한 '쾅' + 짧은 '우웅' |

- 스킬 소리는 다른 효과음보다 크게(-7dB) 굽고, 쓸 때 배경음악을 잠깐 줄인다.
- 배경음악 기본 크기 0.6 → 0.5 (효과음이 더 잘 들리게).
- 스킬이 맞힐 때는 일반 타격음 대신 그 스킬의 맞는 소리.

## 2026-11-26 대장간·보스 패턴 소리 (해성 요청)

`tools/make_world_sfx.py` 로 만들었다 (다시 만들려면 `python tools/make_world_sfx.py`). 천공 낙뢰·대지 가르기 소리는 그대로 둠.

- **대장간** (`fg_*`): 망치(`fg_hammer`)와 강화 결과(`fg_keep` 유지, `fg_success` 성공, `fg_down` 하락, `fg_destroy` 파괴, `fg_craft` 제작)를 모루를 치는 '깡' 소리로 (해성이 녹음해 준 모루질 영상을 재서 맞춤: 1.6kHz 중심 배음이 0.15초쯤 울리다 꺼짐) 바꾸고 전보다 크게(-7dB). '깡'은 화면에서 망치가 내려칠 때(불꽃 튈 때)만 나고, 결과음(유지·성공·하락·파괴·제작)에는 망치 소리를 넣지 않는다 (담금질 '치이익', 부러짐 등).
- **보스 패턴 시작** (`bs_<패턴>`): 보스가 패턴을 시작할 때 한 번. 보스마다 재질을 맞춤.
  - 골렘(갱도): 바위 긁힘·낮은 으르렁 (`rush` `charge` `slam` `boulder` `pound` `summon`)
  - 기사(성채): 쇳소리·칼날·피 (`shield` `combo` `spear` `crescent` `spin`)
  - 수문장(탑): 전기·불꽃·마법 (`lightning` `firespin` `volley` `cage` `homing` `ring`)
  - 마왕: 거꾸로 부풀어 오르는 소리·낮은 울림·촉수·눈 (`darkorb` `brand` `tentacle` `eyes`)
  - 이름이 다른 패턴은 `SfxNames.pattern` 에서 묶음 (예: `spearstand` → `bs_spear`, `rockfall` → `bs_boulder`). 규칙 없는 새 패턴은 `roar`.
- **장판 터짐** (`hz_<모양>`): 전부 새로 만듦. 큰 것(`boulder` `pound` `brand`)은 곡을 살짝 줄임.
