# 귀환진과 마왕 진입부 — 2026-10-29

보스 처치 뒤의 보라색 타원·빛기둥을 청록빛 귀환진으로 바꾸고, 캠프의 작은 회전 문양은 성검이 새겨진 봉인석과 열린 심연 입구로 교체했다. 같은 낡은 석재·금속 테두리를 사용하되, 귀환은 청록빛, 최종전 진입은 보랏빛과 아래로 내려가는 계단으로 구분한다.

## 실제 게임 적용

- 귀환진: `assets/world/portals/return-portal.png`. 세 던전의 기존 보스 처치 조건과 위치를 그대로 사용한다. 큰 빛기둥 대신 작은 청록 입자와 바닥의 약한 빛을 사용한다.
- 봉인 전: `assets/world/portals/abyss-sealed.png`. 세 보스에 대응하는 보석이 순서대로 켜진다. 세 힘이 모두 모이면 금빛으로 봉인 해제 가능 상태를 알린다.
- 봉인 해제 후: `assets/world/portals/abyss-open.png`. 봉인석 안쪽에 계단과 심연이 드러난다. 마왕 처치 후에는 주변 빛을 약하게 한다.
- 캠프 봉인석 중심을 원화 정규화 좌표 `[0.506, 0.776]`에서 `[0.506, 0.700]`으로 옮겼다. 확대된 봉인석이 마을 출구 계단을 덮지 않도록 위쪽 빈 바닥에 배치했다. 시설 표시와 상호작용은 같은 좌표를 사용한다.
- 세 그림은 바닥 레이어에서 캐릭터보다 먼저 그린다. 원근이 그려진 석재 이미지를 회전시키지 않는다. 캐릭터를 통째로 덮는 장식 빛을 줄였다.

기존 E 상호작용, 성검 봉인 해제와 심연 전환 연출, 보스 처치·재생성 조건, 캠프로 귀환하는 동작은 유지한다. 열린 심연은 접근 후 E로 진입하는 지점이며 밟았을 때 자동 추락하는 새 규칙은 추가하지 않는다. 방·통로 마스크나 사용자가 검토 중인 가림 레이어는 수정하지 않는다.

## 원본과 크기

내장 `image_gen`으로 생성한 RGBA PNG 세 장을 바이트 그대로 저장했다. 각각 1536×1024이며 투명 배경을 보존했다. 원본을 늘리거나 다시 칠하지 않고 `hd-art.json`의 표시 크기만 지정했다. 열린/닫힌 봉인석은 생성 원본의 여백 차이를 반영해 실제 외곽 크기가 비슷하도록 맞췄다.

[프롬프트와 선택 원본](portal-design-generation.json). `world_return_portal`, `world_abyss_sealed`, `world_abyss_open` 항목으로 로딩한다.

## 검증 방법

최종 위치 조정본에서 Java 17 테스트 **145개 통과, 실패/오류 0**, 배포 빌드 성공. 실제 렌더러의 30개 화면 생성이 완료됐고 봉인 단계별 보석, 세 던전 귀환진, 캐릭터와 겹침, 미클리어 상태의 포탈 미표시를 확인했다.

```powershell
.\gradlew.bat :core:test :lwjgl3:dist
java -Dfile.encoding=UTF-8 -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.PortalDesignLauncher build/portal-design-final
```

검수 실행기는 별도 QA 저장 폴더를 사용한다. 봉인 0/1/2/3단계·열린 심연·마왕 처치 후·세 던전 귀환진·미클리어 보스방의 10가지 상태를 용사 위치 3곳씩 총 30장으로 캡처한다. 렌더링 GL 오류와 포탈 표시 조건을 검사한다. 전체 캠페인 수동 플레이를 대신하는 검증은 아니다. 캡처는 로컬 `build/`에 보관하며 Git에는 올리지 않는다.
