이동·가림 검토 도구 — 서버 없이 실행

1. 폴더의 START_REVIEW.cmd를 더블클릭합니다.
2. Edge 전용 창 위에 “파일 직접 실행 · 서버 사용 안 함”이 표시됩니다.
3. 그림이 포함된 index.html 하나로 작동합니다. 서버나 인터넷은 필요하지 않습니다.
4. 통과·막힘과 항상 가림·밑동 기준 가림을 따로 표시합니다.
5. “검토안 파일 저장”으로 JSON을 내려받아 보관하세요.
6. 이전 JSON은 “파일 불러오기”로 이어서 사용할 수 있습니다.

http://127.0.0.1:8766/ 은 예전 서버 버전 주소입니다. 지금은 사용하지 않습니다.
채팅의 HTML 링크가 코드 보기로 열리면 폴더에서 START_REVIEW.cmd를 실행하세요.
처음 열 때는 내장 그림 약 44MiB를 읽으므로 잠시 기다릴 수 있습니다.

이 도구의 표시는 게임을 자동으로 바꾸지 않습니다. 검토 JSON을 전달하면 게임에 반영합니다.
