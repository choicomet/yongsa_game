이동-가림-검토.html 또는 index.html을 열어주세요. 두 파일은 같은 내용입니다.

아래의 폴더 유지 안내는 예전 방식 또는 review.template.html 개발용 화면에 해당합니다.

﻿용사가 다한다 — 이동 경계·가림 레이어 검토 (원화 73장)

1. ZIP 전체를 노트북의 원하는 폴더에 압축 해제하세요.
2. 압축을 푼 폴더 안의 index.html을 Chrome 또는 Edge로 여세요.
   ZIP 미리보기에서 열거나 index.html만 따로 옮기면 그림이 나오지 않습니다.
3. 초록은 현재 바닥 마스크입니다.
   “＋ 지나갈 곳”은 하늘색, “− 막을 곳”은 빨간색 요청 표시입니다.
4. 그림별 메모와 공통 요소 기준을 작성하세요.
5. “검토안 파일 저장”으로 yongsa-mask-feedback.json을 다운로드하세요.
6. 다른 컴퓨터에서도 같은 ZIP을 풀고 index.html을 연 뒤,
   “파일 불러오기”로 저장한 JSON을 선택하면 이어서 검토할 수 있습니다.
7. 검토를 마쳤으면 JSON 파일을 채팅에 전달해주세요.

설치, 서버 실행, 인터넷 연결이 필요하지 않습니다.
컴퓨터끼리 자동 동기화되지는 않습니다. 이동 전 JSON을 꼭 저장하세요.
기존 컴퓨터의 http://127.0.0.1:8766 화면에서도 “파일로 받기”로
JSON을 내려받아 노트북에 가져올 수 있습니다.
브라우저 자동 보관은 보조 기능입니다. 폴더 위치나 브라우저를 바꾸면
이어지지 않을 수 있으므로 JSON 파일을 보관하세요.

원화·게임 마스크는 직접 바뀌지 않으며, 표시한 요청만 별도로 저장됩니다.
